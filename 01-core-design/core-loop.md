# Core Loop

**Статус:** Draft

## Основний цикл

1. Гравець отримує контекст або мету.
2. Обирає дію.
3. Виконує дію та приймає ризик.
4. Отримує результат і винагороду.
5. Використовує нові можливості для наступного циклу.

## Перевірка

- Яка головна дія?
- Який вибір робить гравець?
- Який ризик або компроміс?
- Яка винагорода?
- Чому гравець хоче повторити цикл?
