# GameDesign

Робоча база знань для проєктування гри: від бачення та core loop до систем, контенту, UX і плейтестів.

## Навігація

- [00-overview](00-overview/) — бачення гри, дизайн-пілари, аудиторія та глосарій.
- [01-core-design](01-core-design/) — основний ігровий цикл, правила, керування та складність.
- [02-systems](02-systems/) — взаємопов’язані ігрові системи.
- [03-content](03-content/) — персонажі, рівні, предмети й наратив.
- [04-ux](04-ux/) — onboarding, UI/UX та доступність.
- [05-production](05-production/) — roadmap, backlog, плейтести та рішення.
- [06-research](06-research/) — референси, аналіз конкурентів і фідбек.
- [AGENTS.md](AGENTS.md) — принципи професійного геймдизайну та самоперевірка.

## Статуси документів

- **Draft** — робоча гіпотеза.
- **Review** — документ проходить обговорення або плейтест.
- **Approved** — рішення погоджене для реалізації.
- **Deprecated** — застарілий документ, збережений для історії.

Кожен документ має містити мету, правила, приклади, крайні випадки, критерії успіху та поточний статус.# GameDesign
